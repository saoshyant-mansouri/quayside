# The three MSC job descriptions this project is calibrated against

Captured 2026-10-01 from MSC's careers listings. Reproduced here so the
traceability table in [`requirements-map.md`](requirements-map.md) has
something concrete to point at.

## 1 — Artificial Intelligence Engineer

> You are going to join our AI team that uses Generative-AI to build
> conversational interfaces for MSC service exposed to our internal users and
> external customers. You will orchestrate RAG and Function calling to
> implement the next generation of shipping chatbots. You will have the
> opportunity to work with the latest Microsoft AI-tools to interact and
> integrate shipping data with Microsoft 365 ecosystem.
>
> MSC is a "MS stack" based using C#.

Qualifications named:

- Designing and implementing medium to complex Generative AI solutions
- RAG applied to large-scale document collections
- SQL-to-LLM integration with medium to large databases (200+ tables)
- Basic knowledge of Azure platform and key Microsoft cloud services
- CI/CD pipelines using Azure DevOps
- Development of tooling enabling action execution through API integrations
- LLM frameworks, e.g. Semantic Kernel, Microsoft Agentic Framework
- Basic knowledge of low-code agent tooling, e.g. Microsoft Copilot Studio

## 2 — Developer

A C# and .NET specialist role spanning desktop, backend and cloud.

Qualifications named:

- C# with .NET Framework 4.7.2 and .NET 8+
- WPF desktop applications with XAML user interfaces
- RESTful APIs and backend services for distributed systems
- Microsoft SQL Server: T-SQL, schema design, query optimisation, stored
  procedures, performance tuning
- Unit and integration testing (xUnit, NUnit)
- Azure DevOps for CI/CD and PBI management
- Git workflows: branching, merging, pull requests
- Dependency injection and IoC containers
- Asynchronous programming patterns (async/await, Task-based)
- Basic Azure services and cloud development

## 3 — Full Stack Developer

Work on myMSC, the customer-facing shipping platform.

Required:

- Software architecture practices
- Microsoft .NET C#
- Microsoft SQL Server v2012+
- MVC
- jQuery / JavaScript, CSS
- React

Preferred:

- Delivery of large and distributed enterprise applications
- Agile (SCRUM), DevOps implementation
- Bootstrap, Angular, Kendo UI
- Entity Framework, WCF
